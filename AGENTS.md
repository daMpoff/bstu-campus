# БГТУ · Университетская среда

- Перед изменением сверяйся с `docs/spec/`. В интерфейсе используй «Задания», «Новое задание», «Проверка работ».
- Стек: Java 21, Spring Boot 4.1, Maven, PostgreSQL 17, Flyway, React, TypeScript, Vite и Docker Compose. UI и REST API работают с одного адреса.
- Старт демо: `docker compose up --build`. Перед сдачей см. команды тестирования в README.
- Проверяй права в API. Студент видит только задания своей группы и изменяет только свою работу. Преподаватель проверяет работы по своим заданиям.
- Время дедлайна храни как момент UTC. Интерфейс показывает время БГТУ (Europe/Moscow). Изменяй баланс и журнал списаний в одной транзакции.
- Для модульных проверок рейтинга подставляй фиксированное время. Для основных сценариев используй Playwright. Записывай фактические проверки и исправления в `docs/agent-log.md`.
- Сценарий самостоятельной проверки описан в `docs/agent-workflows/verify-assignments.md`.

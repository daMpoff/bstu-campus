# Архитектура

- React + TypeScript + Vite. Интерфейс вызывает REST API на том же origin. Vite проксирует API при локальной разработке.
- Spring Boot 4.1 и Java 21. Spring Security проверяет роли, защищает операции от CSRF и хранит идентификатор сессии в HttpOnly cookie.
- PostgreSQL 17, Flyway для миграций и Spring JdbcClient для доступа к данным. Явные SQL-запросы задают порядок блокировок при изменении работ и рейтинга. Храним пользователей, справочники, задания, целевые группы, состояния работ и журнал АР.
- Регистрация сохраняет пароль как хеш BCrypt и проверяет выбранные значения по справочникам PostgreSQL. Новому студенту назначаются уже опубликованные задания его группы, срок сдачи которых ещё не истёк. Регистрация студента и назначение задания блокируют одну и ту же запись группы, чтобы при одновременных запросах задание попало к студенту.
- Файл работы выдаётся только после проверки доступа. Дедлайн вводится по московскому времени, на API передаётся как UTC.
- Задание планировщика проверяет активные просроченные работы. Транзакция блокирует запись работы и студента, повторно проверяет статус и записывает списание вместе с балансом. Следующий интервал сохраняется в базе. После возврата даётся один интервал до следующего списания, если дедлайн уже прошёл.
- API профиля читает текущий АР и журнал списаний в одной транзакции с повторяемым чтением. Список работ и история включаются в ответ только для владельца профиля. Данные для скачивания работ профиль не возвращает.
- Обзор преподавателя читает задания, счётчики и очередь в одном снимке базы. Прогресс считается по назначенным работам. Рейтинг группы читается из текущих балансов студентов через API, доступный преподавателям.
- Docker Compose запускает приложение и базу. Образ приложения собирает фронтенд и включает его в Spring Boot.

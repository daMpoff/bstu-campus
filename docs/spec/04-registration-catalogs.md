# Справочники регистрации

- 387 групп из [расписания на первый семестр 2026/27](https://raspisanie-bgtu.ru/api/catalog?semester=2026-2027_1_1). Снимок сделан 10 ноября 2026 года. Записи `О-26-СИМ-смоп-Б` и `О-26-СиМ-смоп-Б` совпадают без учёта регистра и имеют одну форму обучения. Сохранён вариант `О-26-СиМ-смоп-Б`.
- 4 факультета, 2 института, политехнический колледж и 22 кафедры из [официальной структуры БГТУ](https://www.tu-bryansk.ru/sveden/struct/). В форму студента включены все семь учебных подразделений. Список преподавателя содержит подразделения, указанные университетом как кафедры.
- Flyway загружает снимок справочников в PostgreSQL. Форма работает без обращения к внешним сайтам. При назначении задания доступны также две группы с предзаполненными демо-аккаунтами.

## Сопоставление групп с подразделениями

Для всех 387 групп подготовлен список по факультетам и институтам со ссылками на учебные документы. Для четырёх групп ПСЖД набора 2024 года связь выведена по программе соседнего набора. [Группы по подразделениям](05-groups-by-faculty.md)

После выбора подразделения поле «Учебная группа» предлагает его группы по формам обучения. В этом же поле можно ввести часть шифра и выбрать группу из подсказок. При смене подразделения поле очищается. Политехнический колледж отображается с пометкой об отсутствии групп в расписании. Сервер проверяет принадлежность группы выбранному подразделению.

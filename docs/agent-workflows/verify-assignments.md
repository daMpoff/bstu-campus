# Проверка сценария заданий

1. Запусти приложение через Docker Compose и открой две браузерные сессии.
2. Под преподавателем назначь задание группе ИВТ-24. Под студентом этой группы открой задание и отправь ссылку или файл.
3. Верни работу, отправь повторно и прими её. Проверь статусы с обеих сторон.
4. Повтори с близким дедлайном. Проверь списание, предел задания и остановку списаний после сдачи.
5. Проверь, что студент другой группы не видит задание и не может сдать работу по прямому запросу API.
6. Запиши в журнал команды сценарий, фактический результат и найденные дефекты.

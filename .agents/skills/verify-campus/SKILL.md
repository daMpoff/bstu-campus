# Проверка БГТУ

1. Из корня репозитория сверь `AGENTS.md`, `docs/spec/01-requirements.md` и раздел «Проверки» в `README.md`. Используй отдельную тестовую базу с демо-аккаунтами. Для нового стенда создай локальный `.verify/verify-campus.env` со строкой `CAMPUS_DEMO=true`. При свободных портах `8080` и `8025` запусти `docker compose --env-file .verify/verify-campus.env -p bstu-verify-campus up --build -d`. Если порты заняты, выбери свободные порты в отдельной конфигурации Compose и задай соответствующие `CAMPUS_URL`, `CAMPUS_MAILBOX_URL` и `CAMPUS_PUBLIC_URL`.
2. Из `backend/` запусти `./mvnw -Dtest=RatingSchedulerTest test` или `.\mvnw.cmd -Dtest=RatingSchedulerTest test` в Windows. Используй фиксированное время в модульных проверках, где тестируешь границу дедлайна и интервалы списаний.
3. Из `frontend/` подготовь зависимости и Chromium по `README.md`, затем запусти `npm run verify:assignments`. Для изменений помощника или MCP добавь `npm run test:e2e -- assistant.spec.ts student-mcp.spec.ts`. Для полной приёмки запусти `npm run test:e2e` и пройди сценарии из `docs/agent-workflows/verify-base.md`.
4. Сверь ключевые результаты с `docs/agent-workflows/verify-assignments.md`. Преподаватель назначает задание ИВТ-24. Студент сдаёт работу, исправляет её после возврата, затем преподаватель принимает её. Студент ИВТ-25 не видит задание и не может сдать его через API. Для просрочки проверь лимит задания, нижнюю границу баланса 0, паузу на проверке, возобновление после возврата и остановку после принятия. Сверь суммы с историей АР и сроки с отображением по МСК. При проверке помощника запроси дедлайны и АР в двух студенческих сессиях и сверь каждый ответ с кабинетом вошедшего студента.
5. При сбое сохрани путь к трассировке Playwright или команду воспроизведения. Определи причину по фактическому результату. После исправления повтори упавший сценарий.
6. Запиши в `docs/agent-log.md` проверенную версию или локальные изменения, команды, число прошедших и упавших тестов, ручные проверки, обнаруженные дефекты, исправления и пропуски. Для каждого пропуска укажи причину.
